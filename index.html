Orange3 Workflow & Model Architecture

This interface operationalizes your Orange3 (.ows) machine learning pipeline trained on grocery_demand_prediction_150.csv.

Pipeline Nodes Verified:
  • File Node: 6 input features (product, stock_quantity, average_daily_sales, day_type, weather, yesterday_unsold_stock)
  • Tree Learner: Binary Decision Tree (min_internal=5, min_leaf=22, max_depth=100)
  • Target Variable: tomorrow_demand_level (High, Medium, Low)
  • Evaluation: Stratified Cross-Validation via Test and Score & Confusion Matrix

Wastage Risk Translation Layer: Combines the Decision Tree's predicted demand class with current stock, yesterday's carryover aging, and product-specific shelf life (e.g., 1–2 days for Milk/Bread vs. 4–5 days for Paneer/Yogurt) to guide store ordering and evening markdowns.
